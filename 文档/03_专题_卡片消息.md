# 专题：卡片消息

KOOK 卡片消息是 JSON 结构：`[卡片1, 卡片2, …]`，每张卡片含若干 `modules`。本库不依赖第三方，直接手工构建。

## 发送卡片

```python
from kook库 import 卡片, 创建按钮元素, 构建卡片消息

卡 = 卡片()                                  # 单张卡片
await bot.发送频道("频道ID", 构建卡片消息([卡]))
```

发送时传 `list/dict` 会自动按**卡片类型(type=10)**序列化，无需手动 JSON。

## 元素工厂（模块内部的子元素）

| 工厂 | 用途 |
|---|---|
| 创建纯文本元素(内容, 转换表情=True) | plain-text，≤2000 字符 |
| 创建KMD元素(内容) | kmarkdown，≤5000 字符 |
| 创建图片元素(地址, 替代文字, 尺寸, 圆形, 备用地址) | 图片元素 |
| 创建按钮元素(文本, 值, 点击类型, 主题, 文本类型) | 按钮(仅能进 action-group) |

## 链式添加模块

`卡片` 的全部"添加…模块"方法都返回自身：

```python
卡 = (卡片(颜色="#007AFF")
      .添加标题模块("标题")
      .添加内容模块("正文", 附件=创建图片元素(url), 附件位置="right")
      .添加段落模块(["左", "中", "右"], 列数=3)
      .添加图片组模块([url1, url2])
      .添加备注模块([创建KMD元素("小字备注")])
      .添加分割线模块()
      .添加文件模块("https://…/a.mp4", 标题="视频", 模块类型="video")
      .添加倒计时模块(结束毫秒, 模式="day")
      .添加邀请模块("邀请码")
      .添加交互模块([创建按钮元素("A", "a", "return-val")]))
```

> 内容模块附件右侧图片用 `创建图片元素`；卡片头部、正文、按钮等常用结构参考 [examples/demo.py](../examples/demo.py)。

## 模板库（开箱即用）

| 模板 | 说明 |
|---|---|
| 状态卡片(标题, 说明, 状态, 备注) | 状态色卡片，状态: 成功/错误/警告/信息 |
| 确认卡片(标题, 说明, 确认文本/值, 取消文本/值) | 确认/取消双按钮 |
| 选项卡片(标题, 选项列表[(文本, 值)], 说明) | 1-4 选项按钮 |
| 用户信息卡片(用户字典, 附加说明) | 头像+昵称+@提及+备注 |

```python
from kook库 import 状态卡片, 确认卡片
await bot.发送频道("频道ID", 状态卡片("部署完成", "v2.1 已上线", "成功"))
await bot.发送频道("频道ID", 确认卡片("删除这条记录？", "将不可恢复", "删除", "del_ok", "取消", "del_no"))
```

## 按钮点击闭环

1. 按钮 `点击类型="return-val"`、`值` 自定义。
2. 用户点击 → KOOK 推送系统事件 `message_btn_click`。
3. 用 `@bot.按钮点击` 接收；事件 `.主体["value"]` 区分哪个按钮。
4. 也支持 `await bot.等待按钮点击(值)` 阻塞式等某按钮。

```python
@bot.按钮点击
async def 处理(事件):
    值 = 事件.主体.get("value")
    if 值 == "del_ok":
        await 事件.回复("已删除")
```

## 限制速查

- 一条消息 1-5 张卡片，总模块 ≤ 50。
- 按钮每行 ≤ 4 个，value 必须唯一以区分点击。
- 图片发送前必须由机器人先经素材接口上传（`bot.发送媒体` 已内置该逻辑）。
