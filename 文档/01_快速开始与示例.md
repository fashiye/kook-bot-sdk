# 快速开始与示例

## 环境要求

- Python ≥ 3.10
- 依赖 `aiohttp`（WebSocket 网关与 REST 共用）

## 安装

```bash
# 从 GitHub 安装
pip install "git+https://github.com/fashiye/kook-bot-sdk.git"
# 或克隆后本地安装(可编辑模式)
git clone https://github.com/fashiye/kook-bot-sdk.git
cd kook-bot-sdk
pip install -e .
```

## 最小可运行示例

```python
from kook库 import 机器人

机器人实例 = 机器人("令牌")

@机器人实例.启动时
async def 上线后(bot):
    print("上线成功")

@机器人实例.命令("!ping")
async def ping(事件, 参数):
    await 事件.引用回复(f"pong! 参数={参数}")

机器人实例.运行()   # 阻塞；Ctrl+C 中断
```

## 示例文件

仓库根 `examples/demo.py` 是一个可直接运行的完整示例，覆盖：

- `启动时` 钩子
- `!ping` / `!卡片` 命令
- 按钮点击系统事件处理
- 链式卡片发送

运行前设置环境变量：

```powershell
$env:KOOK_TOKEN = "你的令牌"
$env:KOOK_CHANNEL_ID = "默认测试频道ID"
python examples/demo.py
```

## 常见起步疑问

- **"HTTP 会话未打开"**：任何 REST 调用前需先 `await 客户端.打开()`；使用 `机器人.运行()` 时由生命周期自动管理。
- **发图片/文件**：见 [机器人.发送媒体](../资源/机器人.py)，支持本地路径/字节/已上传 URL，自动上传并推断消息类型。
- **令牌不生效**：确认以 `1/xxx` 形式粘贴完整令牌，且机器人未被禁用。
