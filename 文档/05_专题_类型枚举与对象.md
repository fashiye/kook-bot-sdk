# 专题：类型、枚举与对象

## 枚举一览

| 枚举 | 取值 | 用途 |
|---|---|---|
| 消息类型 | 纯文本1/图片2/视频3/文件4/音频8/KMD文本9/卡片10/系统255 | 发送 type 与事件 d.type |
| 频道类型 | 分组0/文字1/语音2 | 频道列表/创建过滤 |
| 静音类型 | 麦克风闭麦1/耳机静音2 | 服务器静音接口 |
| 系统事件名 | 按钮点击/用户进出语音/用户信息更新/自己进出服务器 | 系统事件注册与分发 |
| 服务器权限(IntFlag) | 比特位 0-30，31 个成员 | 角色/频道权限位掩码 |

### 权限位用法

```python
from kook库 import 服务器权限

组合值 = int(服务器权限.管理消息 | 服务器权限.踢出用户)   # 组合
# 更新角色权限
await API.服务器角色.更新(服务器ID, 角色ID, 权限=组合值)
```

## 类型化对象（REST 返回 → 中文属性）

自动把原始字典转成对象；保留 `原始数据` 供高级读取：

```python
from kook库 import 用户对象, 频道对象, 服务器对象, 消息对象

用户 = 用户对象.解析(await API.用户.获取信息("用户ID"))
用户.昵称 / 用户.用户名 / 用户.全名 / 用户.是否机器人 / 用户.原始数据
```

| 对象 | 常用属性 |
|---|---|
| 用户对象 | id/用户名/认证号/昵称/头像/是否在线/是否机器人/角色列表/全名 |
| 频道对象 | id/名称/服务器id/类型(枚举)/是否分组/是否加密/人数上限 |
| 服务器对象 | id/名称/主题/图标/服务器主id/助力数/等级 |
| 消息对象 | id/内容/类型(枚举)/作者id/创建时间(datetime) |

> `事件` 内嵌的作者等信息仍以字典为主；需要对象化时把 `extra.author` 等传给 `用户对象.解析`。

## 错误类型

| 异常 | 触发 |
|---|---|
| 接口错误(状态码, 消息, 接口) | KOOK 业务 code ≠ 0；异常携带状态码与出错的接口路径 |
| 令牌错误 | 网关握手鉴权失败(令牌缺失/无效) |

```python
from kook库 import 接口错误
try:
    await API.用户.获取信息("?")
except 接口错误 as e:
    print(e.状态码, e.接口)
```

## 类型注解约定

- 方法参数/返回值全部带中文类型注解，`Optional[X]`/`X|None` 均可。
- 参数语义以 docstring 的 参数/返回/异常 三节为准，二者以源码 docstring 为权威。
