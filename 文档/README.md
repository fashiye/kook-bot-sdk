## 术语速记

- **API / 客户端**：`机器人.API`(HTTP客户端) 聚合各分类资源，REST 只读读写入口。
- **机器人**：网关 + 事件分发 + 便捷方法，长驻在线接收消息。
- **事件**：网关推送消息经 `事件` 对象包装，可在处理器里 `.回复()`。
- **资源**：频道消息/服务器/频道 等按官方域划分的 REST 封装，方法即 KOOK 接口。
