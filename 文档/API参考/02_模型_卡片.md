# 模型_卡片

## `kook库.模型.卡片` —— 卡片消息基础

KOOK 基础卡片消息类：按官方卡片消息文档手工构建原生 JSON 结构，不依赖第三方 SDK。

### `创建纯文本元素`

构造 plain-text 纯文本元素字典。

```python
def 创建纯文本元素(内容: str, 转换表情: bool = True) -> dict[str, typing.Any]
```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 内容: 纯文本内容，最大 2000 个字符。
> 转换表情: 是否把 emoji shortcut 转为真正的 emoji，默认 True。
> 返回:
> 纯文本元素字典，可直接放进模块的 text/elements/fields 字段。
> 异常:
> ValueError: 内容为空或超过 2000 个字符。

</details>

```python
def 创建KMD元素(内容: str) -> dict[str, typing.Any]
```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 内容: KMarkdown 语法文本，最大 5000 个字符。
> 返回:
> KMD 元素字典，可直接放进模块的 text/elements/fields 字段。
> 异常:
> ValueError: 内容为空或超过 5000 个字符。

</details>

### `创建图片元素`

构造 image 图片元素字典。

```python
def 创建图片元素(图片地址: str, 替代文字: str = '', 尺寸: str = 'lg', 圆形: bool = False, 备用地址: str = '') -> dict[str, typing.Any]
```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 图片地址: 图片 URL，推荐先经 asset 接口上传转存得到 KOOK 链接。
> 替代文字: 图片无法加载时显示的替代文字。
> 尺寸: 图片大小，仅图文混排时生效，只能取 sm 或 lg。
> 圆形: 是否裁剪为圆形。
> 备用地址: 外链转存失败时使用的兜底图片地址。
> 返回:
> 图片元素字典，用于 image-group、container、context 等模块。
> 异常:
> ValueError: 图片地址为空或尺寸不合法。

</details>

### `创建按钮元素`

构造 button 按钮交互元素字典。

```python
def 创建按钮元素(文本: str, 值: str = '', 点击类型: str = '', 主题: str = 'primary', 文本类型: str = 'plain-text') -> dict[str, typing.Any]
```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 文本: 按钮上显示的文字。
> 值: 点击后回调/跳转携带的字符串值。
> 点击类型: 空串为无事件；"link" 跳转到值代表的链接；"return-val" 通过按钮点击事件把值回传。
> 主题: 按钮主题色，取值见卡片主题集合。
> 文本类型: 按钮文字格式，只能取 plain-text 或 kmarkdown。
> 返回:
> 按钮元素字典，只能放入 action-group 模块的 elements 列表。
> 异常:
> ValueError: 文本为空或点击类型、文本类型不合法。

</details>

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 卡片列表: 卡片对象列表，最多 5 张，全部模块总数不超过 50。
> 返回:
> 卡片消息数组，其元素为各卡片的导出字典。
> 异常:

</details>

## `卡片`

KOOK 单张卡片，负责累积各类模块并导出可供发送的字典；所有添加方法均支持链式调用。

> 源码位置：`\模型\卡片.py` 第 98 行

- **修改卡片** — 修改卡片的外观配置，传 None 的参数保持不变。

  ```python
  def 修改卡片(self, 颜色: str | None = None, 主题: str | None = None, 尺寸: str | None = None) -> '卡片'
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 颜色: 新的边框十六进制色值。
> 主题: 新的主题，取值见卡片主题集合。
> 尺寸: 新的尺寸，只能取 sm 或 lg。
> 返回:
> 当前卡片对象，便于链式继续添加模块。
> 异常:
> ValueError: 传入的主题或尺寸不合法。

</details>

- **添加内容模块** — 添加 section 内容模块，展示一段文本并可选择在左侧/右侧附带图片或按钮。


> 附件位置: 附件所在侧，left 或 right；按钮不允许放在左侧。

## `kook库.模型.卡片模板` —— 卡片模板库

KOOK 卡片模板库模块：基于 卡片 类预置常用卡片消息模板(状态提示/确认/选项/用户信息等)。

### `状态卡片`

生成带状态色标题的提示卡片(标题 + 正文 + 可选小字备注)。

```python
def 状态卡片(标题: str, 说明: str = '', 状态: str = '信息', 备注: str = '') -> list[dict[str, typing.Any]]
```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 标题: 卡片主标题(≤100 字符)。
> 说明: 正文(≤2000 字符)，空则不渲染正文模块。
> 状态: 状态样式，成功/错误/警告/信息(也接受 success/danger/warning/info)。
> 备注: 底部小字备注(≤2000 字符)，空则省略。
> 返回:
> 单卡片消息数组。
> 异常:
> ValueError: 状态名不受支持。

</details>

### `确认卡片`

```python

```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 标题: 卡片标题。
> 说明: 正文，可空。
> 确认文本/确认值: 确认按钮文字与回传 value。
> 取消文本/取消值: 取消按钮文字与回传 value。
> 颜色: 卡片边框颜色。
> 返回:
> 单卡片消息数组。

</details>
