# 资源_服务器

## `kook库.资源.服务器.服务器` —— 服务器资源(含静音/助力)

KOOK 服务器资源模块：封装服务器(guild)、服务器静音(guild-mute)与服务器助力历史(guild-boost) REST 接口。

## `服务器资源`

服务器分类资源：查询/管理机器人加入的服务器及其成员静音状态。

> 源码位置：`\资源\服务器\服务器.py` 第 11 行

- **获取列表** — 获取机器人已加入的服务器列表。

  ```python
  def 获取列表(self, 页码: int = 1, 页大小: int = 50, 合并全部分页: bool = False) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 页码: 目标页数。
> 页大小: 每页数据数量。
> 合并全部分页: True 时自动翻页并把全量条目合并成一个列表返回。
> 返回:
> 含 items(服务器列表) 与 meta(分页信息) 的 data 字典；开启合并全部分页时返回列表。

</details>

- **获取详情** — 获取服务器详情(含角色与频道列表)。

  ```python
  def 获取详情(self, 服务器ID: str) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 服务器ID: 服务器 id。
> 返回:
> 服务器信息字典。

</details>

- **获取用户列表** — 获取服务器中的用户列表(支持按频道/角色/关键字过滤)。

  ```python
  def 获取用户列表(self, 服务器ID: str, 频道ID: str | None = None, 关键字: str | None = None, 角色ID: int | None = None, 手机认证: bool | None = None, 活跃时间倒序: bool | None = None, 加入时间倒序: bool | None = None, 指定用户ID: str | None = None, 页码: int = 1, 页大小: int = 50, 合并全部分页: bool = False) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 服务器ID: 服务器 id。
> 频道ID: 限定该频道内用户，可选。
> 关键字: 在用户名或昵称中搜索。
> 角色ID: 只取拥有该角色的用户。
> 手机认证: True 只取已手机认证，False 只取未认证，None 不限。
> 活跃时间倒序: True 按活跃时间倒序；False 顺序；None 不排。
> 加入时间倒序: True 按加入时间倒序；False 顺序；None 不排。
> 指定用户ID: 只取该用户的信息。
> 页码: 目标页数。
> 页大小: 每页数据数量。
> 合并全部分页: True 时自动翻页并把全量条目合并成一个列表返回。
> 返回:
> 含 items/meta/user_count/online_count/offline_count 的 data 字典；开启合并全部分页时返回列表。

</details>

- **修改昵称** — 修改用户在服务器内的昵称。

  ```python
  def 修改昵称(self, 服务器ID: str, 昵称: str | None = None, 用户ID: str | None = None) -> None
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 服务器ID: 服务器 id。
> 昵称: 新昵称(2-64 长度)；None 代表清空昵称。
> 用户ID: 目标用户 id；None 修改机器人自己的昵称。
> 返回:
> 无返回值。

</details>

- **离开** — 让机器人离开指定服务器。

  ```python
  def 离开(self, 服务器ID: str) -> None
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 服务器ID: 服务器 id。
> 返回:
> 无返回值。

</details>

- **踢出** — 把用户踢出服务器(机器人需具备踢出成员权限)。

  ```python
  def 踢出(self, 服务器ID: str, 目标用户ID: str) -> None
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 服务器ID: 服务器 id。
> 目标用户ID: 被踢用户 id。
> 返回:
> 无返回值。

</details>

- **静音列表** — 获取服务器当前被静音/闭麦的用户列表。

  ```python
  def 静音列表(self, 服务器ID: str) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 服务器ID: 服务器 id。
> 返回:
> 含 mic(type=1 闭麦) 与 headset(type=2 静音) 两组用户 id 列表的 data 字典。

</details>

- **添加静音** — 在服务器内静音/闭麦用户(需具备管理权限)。

  ```python
  def 添加静音(self, 服务器ID: str, 用户ID: str, 静音方式: 静音类型 | int = <静音类型.耳机静音: 2>) -> None
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 服务器ID: 服务器 id。
> 用户ID: 目标用户 id。
> 静音方式: 1 麦克风闭麦 / 2 耳机静音。
> 返回:
> 无返回值。

</details>

- **删除静音** — 取消服务器内对用户的静音/闭麦。

  ```python
  def 删除静音(self, 服务器ID: str, 用户ID: str, 静音方式: 静音类型 | int = <静音类型.耳机静音: 2>) -> None
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 服务器ID: 服务器 id。
> 用户ID: 目标用户 id。
> 静音方式: 1 麦克风闭麦 / 2 耳机静音，需与添加时一致。
> 返回:
> 无返回值。

</details>

- **助力历史** — 查询服务器的助力包历史(需服务器管理权限)。

  ```python
  def 助力历史(self, 服务器ID: str, 开始时间: int | None = None, 结束时间: int | None = None) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 服务器ID: 服务器 id。
> 开始时间: Unix 秒级时间戳，时间范围起点，可选。
> 结束时间: Unix 秒级时间戳，时间范围终点，可选。
> 返回:
> 按 start_time 倒序的标准分页 data，items 含助力用户与起止时间。

</details>

## `kook库.资源.服务器.邀请` —— 邀请资源

KOOK 邀请资源模块：封装服务器/频道邀请链接(invite)的查询/创建/删除 REST 接口。

## `邀请资源`

邀请分类资源：管理机器人所在服务器的邀请链接。

> 源码位置：`\资源\服务器\邀请.py` 第 10 行

- **获取列表** — 获取服务器或频道的邀请链接列表。

  ```python
  def 获取列表(self, 服务器ID: str | None = None, 频道ID: str | None = None, 页码: int = 1, 页大小: int = 50, 合并全部分页: bool = False) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 服务器ID: 服务器 id，与 频道ID 至少填一个。
> 频道ID: 频道 id。
> 页码: 目标页数。
> 页大小: 每页数据数量。
> 合并全部分页: True 时自动翻页并把全量条目合并成一个列表返回。
> 返回:
> 含 items(邀请列表) 与 meta 的 data 字典；开启合并全部分页时返回列表。

</details>

- **创建** — 创建服务器/频道邀请链接。

  ```python
  def 创建(self, 频道ID: str | None = None, 服务器ID: str | None = None, 有效时长秒: int = 604800, 使用次数: int = -1) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 频道ID: 目标频道 id，与 服务器ID 至少填一个。
> 服务器ID: 目标服务器 id。
> 有效时长秒: 有效秒数，可选 0(永不)/1800/3600/21600/43200/86400/604800，默认 7 天。
> 使用次数: -1 无限制，或 1/5/10/25/50/100。
> 返回:
> data 字典，含 url(如 https://kook.top/xxxx)。

</details>

- **删除** — 删除邀请链接。

  ```python
  def 删除(self, 邀请码: str, 服务器ID: str | None = None, 频道ID: str | None = None) -> None
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 邀请码: 待删除链接的 url_code。
> 服务器ID: 可选，链接所在服务器 id。
> 频道ID: 可选，链接所在频道 id。
> 返回:
> 无返回值。

</details>
