# 资源_消息

## `kook库.资源.消息.频道消息` —— 频道消息资源

KOOK 频道消息资源模块：封装频道聊天消息相关 REST 接口(获取/发送/编辑/删除/回应/置顶/管道)。

### `发送管道消息`

通过消息管道向频道发送消息(需先在开发者后台创建入管道并取得 access_token)。

```python
def 发送管道消息(访问令牌: str, 内容: str | list | dict, 类型: int | None = None, 频道ID: str | None = None, 模板输入: dict[str, Any] | None = None) -> Any
```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 与机器人令牌无关，使用独立连接、不带 Authorization 头，故作为模块级函数提供。
> 参数:
> 访问令牌: 消息管道的 access_token。
> 内容: 文本或卡片结构；未使用模板时发送内容。
> 类型: 消息类型；未填且无模板时默认 KMD。
> 频道ID: 目标文字频道 id(须与管道同一服务器)，不填按管道默认设置。
> 模板输入: 使用模板时传入的模板变量字典(此时忽略 内容/类型)。
> 返回:
> data 字典，含 msg_id。
> 异常:
> 接口错误: KOOK 返回 code 非 0。

</details>

## `频道消息资源`

频道消息分类资源：一条消息 ID 通常指频道消息。

> 源码位置：`\资源\消息\频道消息.py` 第 13 行

- **获取列表** — 获取频道聊天消息列表(以参考消息为中心的前后翻页)。

  ```python
  def 获取列表(self, 频道ID: str, 参考消息ID: str | None = None, 仅置顶: bool | None = None, 查询模式: str | None = None, 页大小: int = 50) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 频道ID: 目标频道 id。
> 参考消息ID: 翻页参考消息 id，不传则查询最新消息。
> 仅置顶: True 只查置顶消息(只能查最新一条)；False/None 查普通消息。
> 查询模式: "before"/"around"/"after"，围绕参考消息的方向，不传默认最新。
> 页大小: 单页条数，默认 50。
> 返回:
> 含 items(消息列表) 的 data 字典。

</details>

- **获取详情** — 获取频道聊天消息详情。

  ```python
  def 获取详情(self, 消息ID: str) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 消息ID: 待查询消息 id。
> 返回:
> 消息详情字典。

</details>

- **发送** — 向频道发送文本或卡片消息。

  ```python
  def 发送(self, 频道ID: str, 内容: str | list | dict, 类型: int | None = None, 引用消息ID: str | None = None, 随机串: str | None = None, 临时用户ID: str | None = None, 模板ID: str | None = None, 回复消息ID: str | None = None) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 频道ID: 目标频道 id。
> 内容: 文本，或卡片数组/字典(自动按 type=10 发送)。
> 类型: 消息类型，默认自动：文本按 9(KMD)，卡片结构按 10。
> 引用消息ID: 回复的源消息 id。
> 随机串: nonce，服务端原样返回，用于幂等与对账。
> 临时用户ID: 传该用户 id 则发临时消息(不入库，仅该用户在频道内可见)。
> 模板ID: 使用消息模板时的模板 id，content 作为模板输入。
> 回复消息ID: 5 分钟内用户刚发的消息 id，首次回复可降低配额消耗。
> 返回:
> data 字典，含 msg_id/msg_timestamp/nonce。

</details>

- **编辑** — 更新频道消息(仅支持 KMD 与卡片消息)。

  ```python
  def 编辑(self, 消息ID: str, 新内容: str | list | dict, 引用消息ID: str | None = None, 临时用户ID: str | None = None, 模板ID: str | None = None, 回复消息ID: str | None = None) -> None
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 消息ID: 待编辑消息 id。
> 新内容: 新文本或新卡片结构。
> 引用消息ID: 传 id 覆盖回复关系；传空串删除回复；None 不改变。
> 临时用户ID: 针对特定用户的临时更新(原消息必须是正常消息)。
> 模板ID: 模板消息 id。
> 回复消息ID: 见发送的同名参数。
> 返回:
> 无返回值。

</details>

- **删除** — 删除频道消息(机器人需有对应权限)。
