## `kook库.模型.事件` —— 事件对象

KOOK 事件对象模块：把网关推送的原始事件字典包装为便于调用的对象。

## `事件`

一条来自网关的 KOOK 事件。封装消息/系统事件通用字段的读取、分类与便捷回复。

> 源码位置：`\模型\事件.py` 第 14 行

- **绑定发送器** — 由机器人分发入口注入便捷发送回调(供 回复/引用回复/私信作者 使用)。

  ```python
  def 绑定发送器(self, 发送器: Callable[[ForwardRef('事件'), str | list | dict, int | None, bool, bool], Awaitable[Any]]) -> None
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 发送器: 见 发送器类型 说明；回调封装了 REST 客户端与通道路由逻辑。
> 返回:
> 无返回值。

</details>

- **_便捷发送** — 调用已注入的发送器执行一次便捷发送(三个公开便捷方法的统一内部入口)。

  ```python
  def _便捷发送(self, 内容: str | list | dict, 类型: int | None, 引用: bool, 私信作者: bool) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 内容: 文本或卡片结构。
> 类型: 消息类型，默认自动推断。
> 引用: True 时带引用原消息。
> 私信作者: True 时改为私信给事件作者。
> 返回:
> 发送接口的 data(含 msg_id)。
> 异常:
> RuntimeError: 事件未绑定发送器(例如非机器人分发创建的事件)。

</details>

- **回复** — 在事件发生的会话里回复(频道消息回频道，私信消息回给对方)。

  ```python
  def 回复(self, 内容: str | list | dict, 类型: int | None = None) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 内容: 文本或卡片结构。
> 类型: 消息类型，默认自动推断。
> 返回:
> 发送接口的 data(含 msg_id)。

</details>

- **引用回复** — 引用原消息进行回复(同 回复，自动带 quote 关联)。

  ```python
  def 引用回复(self, 内容: str | list | dict, 类型: int | None = None) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 内容: 文本或卡片结构。
> 类型: 消息类型，默认自动推断。
> 返回:
> 发送接口的 data(含 msg_id)。

</details>

- **私信作者** — 给本条消息的作者发私信。

  ```python
  def 私信作者(self, 内容: str | list | dict, 类型: int | None = None) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 内容: 文本或卡片结构。
> 类型: 消息类型，默认自动推断。
> 返回:
> 发送接口的 data(含 msg_id)。

</details>

- **匹配** — 判断事件是否匹配某个处理器注册的事件类型。

  ```python
  def 匹配(self, 事件类型: int | str | None) -> bool
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 事件类型: 普通消息为消息类型整型值，系统事件为事件名字符串，None 表示匹配全部。
> 返回:
> 是否匹配。

</details>

## `kook库.模型.对象` —— 类型化数据对象

KOOK 类型化对象模块：把 REST 返回的原始字典包装成带中文属性访问的数据对象。

### `时间戳转时间`

把毫秒时间戳转为本地 datetime(工具函数，供各对象的时间属性复用)。

```python
def 时间戳转时间(毫秒值: Any) -> datetime.datetime | None
```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 毫秒值: 毫秒时间戳(数字或字符串)。
> 返回:
> 本地时间对象；无效输入返回 None。

</details>

## `kook库.模型.常量` —— 接口常量

KOOK 接口常量模块：存放 REST 请求公共常量，供请求引擎与各资源模块共享引用，避免模块间循环导入。
