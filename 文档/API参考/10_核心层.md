# 核心层

## `kook库.核心.HTTP引擎` —— REST 请求引擎

KOOK HTTP 引擎模块：底层 REST 请求引擎，位于核心层。

## `HTTP引擎`

KOOK REST 请求引擎：持有会话与鉴权令牌，统一负责请求发送与错误码解析。

> 源码位置：`\核心\HTTP引擎.py` 第 15 行

- **打开** — 创建 aiohttp 会话。返回: 无返回值。

  ```python
  def 打开(self) -> None
  ```

- **关闭** — 关闭 aiohttp 会话并释放连接池。返回: 无返回值。

  ```python
  def 关闭(self) -> None
  ```

- **请求** — 发送一次 JSON REST 请求并返回 data 字段。

  ```python
  def 请求(self, 方法: str, 接口路径: str, 查询参数: dict[str, Any] | None = None, 数据: dict[str, Any] | None = None) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 方法: HTTP 方法(GET/POST)。
> 接口路径: 接口路径，如 "/message/create"。
> 查询参数: URL 查询参数，GET 请求使用。
> 数据: 请求体字典，POST 请求以 JSON 发送。
> 返回:
> KOOK 响应的 data 字段。
> 异常:
> RuntimeError: 会话未打开。
> 接口错误: KOOK 返回 code 非 0。

</details>

- **上传文件** — 以 multipart/form-data 上传文件(用于素材上传等接口)并返回 data 字段。

  ```python
  def 上传文件(self, 接口路径: str, 文件字段名: str, 文件字节: bytes, 文件名: str, 附加字段: dict[str, Any] | None = None) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 接口路径: 接口路径，如 "/asset/create"。
> 文件字段名: 表单中文件字段名，KOOK 素材接口为 "file"。
> 文件字节: 文件二进制内容。
> 文件名: 上传时展示的文件名(需带扩展名以判定类型)。
> 附加字段: 额外的普通表单字段，可选。
> 返回:
> KOOK 响应的 data 字段。
> 异常:
> RuntimeError: 会话未打开。
> 接口错误: KOOK 返回 code 非 0。

</details>

- **_解析响应** — 统一解析 KOOK 响应：读取 JSON 并检查业务状态码。

  ```python
  def _解析响应(self, 响应: aiohttp.client_reqrep.ClientResponse, 接口路径: str) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 响应: aiohttp 响应对象。
> 接口路径: 请求的接口路径，用于错误提示。
> 返回:
> KOOK 响应的 data 字段。
> 异常:
> 接口错误: KOOK 返回 code 非 0。

</details>

## `kook库.核心.资源基座` —— 资源基类与工具

KOOK REST 资源基类模块：所有分类资源对象(频道消息/服务器/用户等)的公共基类与内容整理工具。

### `整理发送内容`

把要发送的消息内容整理为(消息类型, content字符串)。供频道消息/私信消息等资源复用。

```python
def 整理发送内容(内容: str | list | dict, 显式类型: int | None = None) -> tuple[int, str]
```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 内容: 文本字符串，或卡片 JSON 数组/字典。
> 显式类型: 调用方显式指定的消息类型，None 则自动推断。
> 返回:
> 二元组：消息类型整型值、序列化后的内容字符串。

</details>

## `资源基类`

REST 分类资源的公共基类：持有底层客户端，所有接口方法经 _请求() 统一转发。

> 源码位置：`\核心\资源基座.py` 第 29 行

- **_请求** — 把 REST 请求转发给底层客户端统一执行(鉴权、超时、错误码处理都集中在客户端)。

  ```python
  def _请求(self, 方法: str, 接口路径: str, 查询参数: dict[str, Any] | None = None, 数据: dict[str, Any] | None = None) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 方法: HTTP 方法(GET/POST)。
> 接口路径: 接口路径，如 "/message/create"。
> 查询参数: URL 查询参数，GET 请求使用。
> 数据: 请求体字典，POST 请求使用。
> 返回:
> KOOK 响应的 data 字段，具体结构随接口而定。

</details>

- **_上传文件** — 把 multipart 文件上传委托给底层客户端统一处理(素材/服务器表情等接口复用)。

  ```python
  def _上传文件(self, 接口路径: str, 文件字段名: str, 文件字节: bytes, 文件名: str, 附加字段: dict[str, Any] | None = None) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 接口路径: 接口路径，如 "/asset/create"。
> 文件字段名: 表单中文件字段名(如 asset 为 "file"，表情为 "emoji")。
> 文件字节: 文件二进制内容。
> 文件名: 上传时展示的文件名(需带扩展名以判定类型)。
> 附加字段: 额外的普通表单字段，可选。
> 返回:
> KOOK 响应的 data 字段。

</details>

- **_合并分页** — 把标准分页接口(返回 items + meta.page_total)的列表自动翻页拉全并合并。

  ```python
  def _合并分页(self, 获取一页: Callable[[int, int], Awaitable[dict[str, Any]]], 起始页码: int = 1, 页大小: int = 50) -> list[dict[str, typing.Any]]
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 供各分类资源列表方法的"合并全部分页"选项复用。
> 参数:
> 获取一页: 异步回调，入参(页码, 每页条数)，返回该页 data 字典(含 items/meta)。
> 起始页码: 从第几页开始，默认 1。
> 页大小: 每页条数，默认 50。
> 返回:
> 合并后的全量 items 列表。

</details>

## `kook库.核心.网关` —— WebSocket 网关

KOOK WebSocket 网关模块：负责连接网关、握手、心跳保活、按序接收事件以及断线自动重连。

## `网关`

KOOK WebSocket 网关客户端。 负责连接(可重连)、心跳、事件帧的 sn 有序处理，并把每条事件字典交给上层回调。

> 源码位置：`\核心\网关.py` 第 22 行

- **启动** — 启动网关主循环任务。返回: 无返回值。

  ```python
  def 启动(self) -> None
  ```

- **停止** — 停止网关：置停止标志并关闭当前连接。返回: 无返回值。

  ```python
  def 停止(self) -> None
  ```

- **等待退出** — 阻塞直到主循环任务结束。返回: 无返回值。

  ```python
  def 等待退出(self) -> None
  ```

- **_主循环** — 连接主循环：获取网关地址→连接→运行，失败按退避策略重试直到停止。

  ```python
  def _主循环(self) -> None
  ```

- **_运行连接** — 处理单条连接：等待 hello 握手，然后进入接收循环并管理心跳任务。

  ```python
  def _运行连接(self, 连接) -> None
  ```

- **_处理信令** — 按信令编号分发处理一条网关帧。返回: 无返回值。

  ```python
  def _处理信令(self, 连接, 帧: dict[str, typing.Any]) -> None
  ```

- **_心跳循环** — 每 30±5 秒发送一次 ping，6 秒内未收到 pong 则断开触发重连。

  ```python
  def _心跳循环(self, 连接) -> None
  ```

- **_处理事件帧** — 按 sn 有序处理事件：去重、乱序暂存、按序回调。

  ```python
  def _处理事件帧(self, 事件数据: dict[str, typing.Any], sn: int) -> None
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 事件数据: 信令 s=0 的 d 字段。
> sn: 该事件的消息序号。
> 返回:
> 无返回值。

</details>
