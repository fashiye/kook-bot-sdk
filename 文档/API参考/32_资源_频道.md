# 资源_频道

## `kook库.资源.频道.频道` —— 频道资源

KOOK 频道资源模块：封装服务器频道(channel)的增删改查与语音频道成员操作 REST 接口。

## `频道资源`

频道分类资源：管理服务器内文字/语音/分组频道。

> 源码位置：`\资源\频道\频道.py` 第 11 行

- **获取列表** — 获取服务器内频道列表。

  ```python
  def 获取列表(self, 服务器ID: str, 类型: 频道类型 | int | None = None, 父频道ID: str | None = None, 页码: int = 1, 页大小: int = 50, 合并全部分页: bool = False) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 服务器ID: 服务器 id。
> 类型: 频道类型过滤(分组0/文字1/语音2)，None 返回全部。
> 父频道ID: 限定某分组下的子频道。
> 页码: 目标页数。
> 页大小: 每页数据数量。
> 合并全部分页: True 时自动翻页并把全量条目合并成一个列表返回。
> 返回:
> 含 items(频道列表) 与 meta 的 data 字典；开启合并全部分页时返回列表。

</details>

- **获取详情** — 获取频道详情。

  ```python
  def 获取详情(self, 频道ID: str, 需要子频道: bool = False) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 频道ID: 频道 id。
> 需要子频道: True 时返回子频道 id 列表(用于分组频道)。
> 返回:
> 频道信息字典。

</details>

- **创建** — 创建服务器频道(文字/语音/分组)。

  ```python
  def 创建(self, 服务器ID: str, 名称: str, 类型: 频道类型 | int = <频道类型.文字: 1>, 父频道ID: str | None = None, 人数上限: int = 0, 音质: str = '2', 是分组: bool = False) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 服务器ID: 服务器 id。
> 名称: 频道名称。
> 类型: 频道类型，默认文字频道。
> 父频道ID: 父分组频道 id，可选。
> 人数上限: 语音频道人数上限，最大 99，0 表示默认。
> 音质: 语音音质，1 流畅/2 正常/3 高质量。
> 是分组: 是否创建分组频道；为真时其余参数无效(只传三个字段)。
> 返回:
> 新频道信息字典(含 id)。

</details>

- **更新** — 编辑频道(按需传参，None 字段保持不变)。

  ```python
  def 更新(self, 频道ID: str, 名称: str | None = None, 排序: int | None = None, 父频道ID: str | None = None, 频道简介: str | None = None, 慢速模式毫秒: int | None = None, 人数上限: int | None = None, 音质: str | None = None, 密码: str | None = None) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 频道ID: 目标频道 id。
> 名称: 新频道名称。
> 排序: 频道排序值(越小越靠前)。
> 父频道ID: 移入的新分组 id；传 "0" 代表移出分组。
> 频道简介: 文字频道简介。
> 慢速模式毫秒: 文字频道发言间隔(仅支持官方枚举值：0/5000/10000/15000/30000/60000/120000/300000/600000/900000/1800000/3600000/7200000/21600000)。
> 人数上限: 语音频道容量，最大 99。
> 音质: 语音音质，1 流畅/2 正常/3 高质量。
> 密码: 语音频道进入密码。
> 返回:
> 更新后的频道信息字典。

</details>

- **删除** — 删除频道(机器人需具备对应权限)。

  ```python
  def 删除(self, 频道ID: str) -> None
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 频道ID: 待删除频道 id。
> 返回:
> 无返回值。

</details>

- **语音用户列表** — 获取语音频道中当前在线的用户列表。

  ```python
  def 语音用户列表(self, 频道ID: str) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 频道ID: 语音频道 id。
> 返回:
> 用户字典列表。

</details>

- **移动语音用户** — 把若干在线用户移动到另一个语音频道。

  ```python
  def 移动语音用户(self, 目标频道ID: str, 用户ID列表: list[str]) -> None
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 目标频道ID: 目标语音频道 id。
> 用户ID列表: 待移动用户 id 数组(须在当前语音频道在线)。

</details>

## `kook库.资源.频道.频道角色权限` —— 频道角色权限资源

KOOK 频道角色权限资源模块：封装频道角色权限(channel-role)的查看/创建/更新/同步/删除 REST 接口。

## `频道角色权限资源`

频道角色权限分类资源：对某个频道设置针对角色或用户的权限覆写规则。

> 源码位置：`\资源\频道\频道角色权限.py` 第 10 行

- **获取详情** — 获取频道角色权限详情(含角色/用户两类覆写规则与是否同步分组权限)。

  ```python
  def 获取详情(self, 频道ID: str) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 频道ID: 频道 id。
> 返回:
> 含 permission_overwrites/permission_users/permission_sync 的 data 字典。

</details>

- **创建** — 给频道新增一条角色或用户的权限覆写规则。

  ```python
  def 创建(self, 频道ID: str, 覆写对象: str, 对象ID: str | None = None) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 频道ID: 频道 id(传分组 id 会同步到其 sync=1 子频道)。
> 覆写对象: 规则对象类型，仅可为 "role_id"(角色)或 "user_id"(用户)。
> 对象ID: 角色 id 或用户 id(取决于覆写对象)。
> 返回:
> 含 user_id/role_id、allow、deny 的 data 字典。

</details>

- **更新** — 更新频道上某角色/用户的权限覆写规则。

  ```python
  def 更新(self, 频道ID: str, 覆写对象: str, 对象ID: str, 允许权限: int = 0, 拒绝权限: int = 0) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 频道ID: 频道 id(传分组 id 会同步到其 sync=1 子频道)。
> 覆写对象: "role_id" 或 "user_id"。
> 对象ID: 角色 id 或用户 id。
> 允许权限: 允许的权限位掩码值。
> 拒绝权限: 拒绝的权限位掩码值。
> 返回:
> 含 user_id/role_id、allow、deny 的 data 字典。

</details>

- **同步** — 把分组频道的权限配置同步应用到子频道。

  ```python
  def 同步(self, 频道ID: str) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 频道ID: 分组频道 id。
> 返回:
> 同步后的 permission_overwrites/permission_users 的 data 字典。

</details>

- **删除** — 删除频道上某角色/用户的权限覆写规则。

  ```python
  def 删除(self, 频道ID: str, 覆写对象: str, 对象ID: str | None = None) -> None
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 频道ID: 频道 id(传分组 id 会同步到其 sync=1 子频道)。
> 覆写对象: "role_id" 或 "user_id"。
> 对象ID: 角色 id 或用户 id。
> 返回:
> 无返回值。

</details>

## `kook库.资源.频道.语音` —— 语音资源

KOOK 语音资源模块：封装机器人加入/离开语音频道、语音连接保活及查询用户在语音频道 REST 接口。

## `语音资源`

语音分类资源：机器人语音推流(加入后获得媒体服务器地址)与频道状态查询。

> 源码位置：`\资源\频道\语音.py` 第 12 行

- **加入** — 让机器人加入语音频道并申请推流地址。

  ```python
  def 加入(self, 频道ID: str, 密码: str | None = None, 音频源标识: str = '1111', 音频负载类型: str = '111', 复用RTP端口: bool = True) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 频道ID: 需要加入的语音频道 id。
> 密码: 加密房间的进入密码，可选。
> 音频源标识: RTP ssrc，默认 1111，不熟悉请勿改动。
> 音频负载类型: RTP payload_type，默认 111，不熟悉请勿改动。
> 复用RTP端口: 是否 rtcp 与 rtp 共用一个端口，默认 True。
> 返回:
> 含 ip/port/rtcp_mux/bitrate/audio_ssrc/audio_pt 的推流配置字典。

</details>

- **已加入列表** — 获取机器人当前加入的语音频道列表。


<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 返回:

</details>

- **离开** — 让机器人主动离开语音频道并释放推流资源。
