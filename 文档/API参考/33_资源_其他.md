## `kook库.资源.素材` —— 素材上传资源

KOOK 素材资源模块：封装媒体文件上传(asset) REST 接口。

## `素材资源`

素材分类资源：上传图片/视频/文件以换取 KOOK 站内资源地址(发消息前需先上传)。

> 源码位置：`\资源\素材.py` 第 10 行

- **上传** — 上传媒体文件(multipart，支持图片、.mp4/.mov 视频与任意文件)。

  ```python
  def 上传(self, 文件字节: bytes, 文件名: str) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 文件字节: 文件二进制内容。
> 文件名: 文件名(需带扩展名，服务端据此判定资源类型)。
> 返回:
> data 字典，含 url(资源地址)，可直接作为图片/视频/文件消息的 content。

</details>

## `kook库.资源.帖子` —— 帖子资源

KOOK 帖子资源模块：封装帖子分区(category)与帖子(thread)的发布/评论/查询/删除 REST 接口。

## `帖子资源`

帖子分类资源：管理服务器帖子频道中的分区、帖子与评论。

> 源码位置：`\资源\帖子.py` 第 10 行

- **获取分区列表** — 获取帖子频道的分区列表。

  ```python
  def 获取分区列表(self, 频道ID: str) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 频道ID: 帖子频道 id。
> 返回:
> 含 list(分区数组) 的 data 字典，分区含 id/name/allow/deny/roles。

</details>

- **创建** — 发布一篇帖子。

  ```python
  def 创建(self, 服务器ID: str, 频道ID: str, 标题: str, 内容: str | list | dict, 分区ID: str | None = None, 封面: str | None = None) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 服务器ID: 帖子所在服务器 id。
> 频道ID: 帖子频道 id。
> 标题: 帖子标题。
> 内容: 正文(文本或卡片结构，规则同频道消息)。
> 分区ID: 帖子分区 id；None 进默认综合分区。
> 封面: 封面图片 url，可选。
> 返回:
> 新帖子详情字典(含 id/post_id)。

</details>

- **回复** — 对帖子发表评论或回复某条评论(楼中楼)。

  ```python
  def 回复(self, 频道ID: str, 帖子ID: str, 内容: str, 回复对象ID: str | None = None) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 频道ID: 帖子频道 id。
> 帖子ID: 目标帖子 id。
> 内容: 评论文本。
> 回复对象ID: 回复他人评论时的 post_id；评论主楼则不传。
> 返回:
> 新评论详情字典。

</details>

- **获取详情** — 获取帖子详情(含主楼内容与统计)。

  ```python
  def 获取详情(self, 频道ID: str, 帖子ID: str) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 频道ID: 帖子频道 id。
> 帖子ID: 目标帖子 id。
> 返回:
> 帖子详情字典。

</details>

- **获取列表** — 获取帖子列表。

  ```python
  def 获取列表(self, 频道ID: str, 分区ID: str | None = None, 排序: int | None = None, 页大小: int = 30, 翻页时间: int | None = None) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 频道ID: 帖子频道 id。
> 分区ID: 帖子分区 id，None 默认综合分区。
> 排序: 1 最新回复 / 2 最新创建；None 按频道设置。
> 页大小: 单页条数，默认 30。
> 翻页时间: 翻页起点时间(取上一页最后一帖对应时间；sort=1 用 latest_active_time，sort=2 用 create_time)。
> 返回:
> 含 items(帖子列表) 的 data 字典。

</details>

- **删除** — 删除帖子或其中的评论/回复。

  ```python
  def 删除(self, 频道ID: str, 帖子ID: str | None = None, 楼ID: str | None = None) -> None
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 频道ID: 帖子频道 id。
> 帖子ID: 删除整帖时的帖子 id(与 楼ID 同时给则只删对应楼)。
> 楼ID: 删除单条评论/回复时的 post_id。
> 返回:
> 无返回值。

</details>

- **获取回复列表** — 获取帖子的评论/回复列表(可查看楼中楼)。

  ```python
  def 获取回复列表(self, 频道ID: str, 帖子ID: str, 排序方向: str = 'asc', 页码: int = 1, 楼ID: str | None = None, 翻页时间: str | None = None, 页大小: int | None = None) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 频道ID: 帖子频道 id。
> 帖子ID: 目标帖子 id。
> 排序方向: "asc" 升序或 "desc" 降序。
> 页码: 页码。
> 楼ID: 某条评论的 post_id，查看其楼中楼时传。
> 翻页时间: 某条回复的 create_time，用于分页定位。
> 页大小: 单页条数。
> 返回:
> 含 meta 与 items(评论列表) 的 data 字典。

</details>

## `kook库.资源.模板` —— 消息模板资源

KOOK 消息模板资源模块：封装消息模板(template)的增删改查 REST 接口。

## `模板资源`

消息模板分类资源：模板以 twig 语法书写，content 即模板正文。

> 源码位置：`\资源\模板.py` 第 10 行

- **获取列表** — 获取当前机器人的全部消息模板。

  ```python
  def 获取列表(self) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 返回:
> 含 items(模板列表) 的 data 字典。

</details>

- **创建** — 创建消息模板。

  ```python
  def 创建(self, 标题: str, 内容: str, 渲染类型: int = 0, 消息格式: int = 1, 测试数据: str | None = None, 测试频道: str | None = None) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 标题: 模板标题，必传。
> 内容: twig 模板正文，必传。
> 渲染类型: 渲染引擎类型，目前固定 0(twig)。
> 消息格式: 1 kmd 消息 / 2 json 卡片 / 3 yaml 卡片。
> 测试数据: 控制台测试用的样例输入 JSON 文本，可选。
> 测试频道: 控制台测试用的频道 id，可选。
> 返回:
> data 字典，含 model(新模板，含 id)。

</details>

- **更新** — 更新消息模板(按需传参)。

  ```python
  def 更新(self, 模板ID: str, 标题: str | None = None, 内容: str | None = None, 渲染类型: int | None = None, 消息格式: int | None = None, 测试数据: str | None = None, 测试频道: str | None = None) -> Any
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 模板ID: 目标模板 id，必传。
> 标题: 新标题。
> 内容: 新模板正文。
> 渲染类型: 渲染引擎类型(0=twig)。
> 消息格式: 1 kmd / 2 json 卡片 / 3 yaml 卡片。
> 测试数据: 测试样例输入。
> 测试频道: 测试频道 id。
> 返回:
> data 字典，含 model(更新后的模板)。

</details>

- **删除** — 删除消息模板(删除后使用该模板的消息将无法发送)。

  ```python
  def 删除(self, 模板ID: str) -> None
  ```

<details><summary>参数 / 返回 / 异常 完整说明</summary>

> 参数:
> 模板ID: 目标模板 id。
> 返回:
> 无返回值。

</details>
