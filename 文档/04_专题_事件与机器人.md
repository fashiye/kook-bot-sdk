# 专题：事件与机器人

## 事件如何到达

```
KOOK 网关 ──> 网关(核心) ──按sn有序──> 机器人._处理网关事件
                                        ├─ 唤醒 等待器(等待文本/按钮)
                                        └─ 顺序调用匹配的注册处理器(事件)
```

处理器签名固定：`async def 处理器(事件) -> None`（命令路由额外收参数）。

## 常用事件字段

| 属性 | 含义 |
|---|---|
| 通道类型 | `GROUP` 频道消息 / `PERSON` 私信 |
| 类型 / 是否系统事件 | 消息类型；255=系统事件 |
| 系统事件名 | 系统事件的具体名(如 message_btn_click) |
| 目标ID / 作者ID / 消息ID | 会话与消息定位 |
| 内容 | 消息正文 |
| 主体 | 系统事件取 extra.body(按钮 value 等)，普通消息取整条原始数据 |
| 附加数据 | extra 原样数据(作者信息、服务器 id 等) |

## 便捷回复（处理器里零查找）

| 方法 | 行为 |
|---|---|
| `await 事件.回复(内容)` | 频道回频道 / 私信回对方 |
| `await 事件.引用回复(内容)` | 同上并带引用原消息 |
| `await 事件.私信作者(内容)` | 无论来源都私信作者 |

```python
@bot.文本消息
async def 处理(事件):
    if "你好" in 事件.内容:
        await 事件.回复("你好呀 👋")
```

## 事件注册方式

| 方式 | 说明 |
|---|---|
| `@bot.注册处理器(类型)` | 消息类型 int / 系统事件名 str / None 全部 |
| `@bot.文本消息` | 频道与私信的纯文本(1)+KMD(9) |
| `@bot.命令("!x")` | 命令路由，处理器收 (事件, 参数文本) |
| `@bot.关键词("词")` | 正文含词即触发 |
| `@bot.按钮点击` | 卡片按钮点击系统事件 |

## 按钮点击：创建即绑定回调（推荐）

相比 `@bot.按钮点击` 内手写 `if 值 == …` 分发，推荐在**构建按钮时直接绑定处理函数**：

```python
from kook库 import 卡片, 创建按钮元素

async def 确认支付(事件):
    await 事件.回复("✅ 已确认，订单进入抢单阶段")

卡 = 卡片().添加交互模块([创建按钮元素("确认支付", "pay_001", 回调=确认支付)])
await bot.发送频道("频道ID", 卡)
```

行为约定：

| 约定 | 说明 |
|---|---|
| 回调签名 | 与事件处理器一致 `async def 处理(事件)`；同步函数亦可(返回协程自动等待) |
| 自动 return-val | 传入回调后按钮自动置为 `return-val`；`link` 按钮不能绑回调 |
| value 回查键 | 重复绑定同一 value 后注册覆盖；一次性交互结束可用 `按钮回调中心.移除(值)` 清理 |
| 分发短路 | 命中绑定回调后不再进入 `@bot.按钮点击`；未绑定按钮仍走普通事件处理器(两种接法可共存) |

`按钮回调中心` 由顶层包直接导出。

## 阻塞式等待（交互语法糖）

在任意 async 上下文内可用（不占用常驻处理器）：

```python
async def 问卷(bot):
    await bot.发送频道("频道ID", "你喜欢哪门语言？回复数字")
    回答 = await bot.等待文本(关键词="Python", 频道ID="频道ID", 作者ID="xxx", 超时秒=30)
    if 回答 is not None:
        await bot.发送频道("频道ID", "收到！" + 回答.内容)
    else:
        await bot.发送频道("频道ID", "超时未收到回复")
```

| 方法 | 用途 |
|---|---|
| `await bot.等待事件(谓词, 超时)` | 通用等待，谓词返回是否命中 |
| `await bot.等待文本(关键词, 频道ID, 作者ID, 超时)` | 等文本消息 |
| `await bot.等待按钮点击(值, 超时)` | 等指定 value 的按钮点击 |

等待器由事件分发自动喂入；超时自动清理，不泄漏。

## 顶层便捷发送

| 方法 | 说明 |
|---|---|
| `await bot.发送频道(频道ID, 内容)` | 文本/卡片直发 |
| `await bot.发送私信(用户ID, 内容)` | 私信直发 |
| `await bot.发送媒体(频道ID, 本地路径/字节/URL, 文件名, 类型)` | 自动上传后发媒体 |
| `await bot.私信媒体(用户ID, …)` | 同前，发私信媒体 |

## 生命周期与启停

```python
bot = 机器人(令牌)

@bot.启动时
async def 启动(bot): ...          # 连接成功后回调(bot 自身)

@bot.关闭时
async def 关闭(bot): ...          # 关闭前清理回调

bot.运行()                        # 阻塞主流程(asyncio.run)
bot.请求停止()                    # 在外部事件循环中请求优雅停止
```

## 建议

- 处理器内务必 `try` 网络调用，或依赖本库统一捕获打印日志（单个处理器异常不会拖垮分发）。
- 若机器人会互聊，请过滤 `事件.作者 是否机器人`，防止自循环触发发送量管控/封禁。
