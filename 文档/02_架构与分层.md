# 架构与分层

## 三层结构

```
kook库/
  __init__.py        # 公共入口：只做 re-export，不写实现
  模型/               # 纯领域数据，无网络
  核心/               # 会话与运行时
  资源/               # REST 分类资源 + 组合层
```

依赖单向，禁止反向：

```
模型 ← 核心 ← 资源 ← __init__ 导出
```

## 各层职责

### 模型层（无 IO）

| 模块 | 内容 |
|---|---|
| 类型 | 消息类型/频道类型/静音类型/系统事件名/服务器权限(IntFlag) |
| 错误 | 接口错误、令牌错误 |
| 事件 | 网关事件对象；含便捷回复（由注入的发送器驱动） |
| 对象 | REST 字典 → 中文属性的数据类（用户/频道/服务器/消息） |
| 卡片 | 原生卡片 JSON 构建器（全部方法返回 self 支持链式） |
| 卡片模板 | 状态/确认/选项/用户信息 现成卡片 |
| 常量 | REST 接口根地址 |

### 核心层

| 模块 | 职责 |
|---|---|
| HTTP引擎 | aiohttp 会话、鉴权头(Bot/用户)、请求/上传、错误码解析 |
| 资源基座 | 资源基类(_请求/_上传文件/_合并分页) 与消息内容整理 |
| 网关 | WebSocket：握手、心跳(30±5s)、sn 有序去重分发、指数退避重连 |

### 资源层

| 模块 | 内容 |
|---|---|
| 客户端 | HTTP客户端：Bot 鉴权，聚合 14 个分类资源 + 获取网关地址 + ID↔名称解析 |
| 机器人 | 组合 客户端+网关：事件注册/命令/关键词/等待，便捷发送 |
| 消息 / 服务器 / 频道 子包 | 按 KOOK 官方域分组的分类资源 |

## 核心对象关系

```
机器人 ──API──> HTTP客户端 ─┬─ 频道消息/私信消息/会话 ─...
     │                      ├─ 服务器/角色/表情/邀请
     │                      ├─ 频道/频道角色权限/语音
     │                      └─ 用户/素材/帖子/模板
     └─网关(WebSocket) ─ 事件 ─> 事件分发/等待器 ─> 用户处理器
```

## 设计约定

- 所有分类资源只做"拼参数、调接口"，请求细节收敛在 HTTP引擎，**避免重复网络代码**。
- 资源方法名使用中文；docstring 必含 参数/返回/异常。
- 扩展新接口 = 在对应资源类新增一个 async 方法，复用 `_请求`。
- 列表接口如需自动翻页，复用 `_合并分页`（返回 `items + meta.page_total` 的标准分页）。
