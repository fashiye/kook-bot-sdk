# 常见问题与安全

## 消息配额与限流

- 单开发者账号所有机器人合计：每日 **10,000 条**主动消息（UTC+8 12:00 重置）。
- 计入配额：`message/create·update`、`direct-message/create·update`、`thread/create·reply`。
- 首次回复用户 5 分钟内消息可显著降低配额消耗（对应各发送方法的 `回复消息ID`）。
- 请求过频会触发限流：本库未内置重试，业务侧请自行退避。

## 令牌安全（务必）

1. 机器人令牌等同密码，**严禁提交进 git**；库根 `.gitignore` 已忽略 `.env`。
2. 不要把令牌贴在公共聊天/截图里。**只要在会话中明文出现过，建议立即到开发者后台重置。**
3. 管道消息 `/message/send-pipemsg` 的 access_token 独立于机器人令牌，同样妥善保管。

## 常见报错排查

| 报错 | 原因/处理 |
|---|---|
| HTTP 会话未打开 | 先 `await 客户端.打开()`；机器人场景由生命周期托管 |
| 令牌无效/握手失败(令牌错误) | 令牌被禁用/过期；到后台核对并重置 |
| 找不到资源 | 发图片/视频/文件时 content 必须来自**本机器人上传**的资源(用 素材.上传 或 bot.发送媒体) |
| 消息发送成功但客户端不可见 | 检查机器人是否在该服务器/频道，以及权限 |
| 接口 code 非 0 | 捕获 `接口错误` 查看 `.状态码/.接口` 后按官方错误码表处理 |

## 媒体与上传建议

- `素材.上传` 支持图片、`.mp4/.mov` 视频、任意文件；表情上传限定 PNG ≤ 256KB。
- `bot.发送媒体(频道ID, "本地路径")` 内部= 读取→上传→按扩展名发对应类型；字节来源需给 `文件名`。
- 上传返回的 url 属于站内资源，直接用其发消息即可。

## 网关注意事项

- WebSocket 连接（不是 REST）可接收事件；`user/offline`/`user/online` 仅对 **Webhook 模式**有效。
- 网关内置断线指数退避重连（1s→60s），令牌失效时不重试以免空转。
- 事件已按 sn 去重与乱序暂存，处理器收到的顺序是可靠的；多实例部署请自行设计去重。

## 扩展指引

- 新接口：在对应资源类加 `async def 方法(...) -> Any:`，内部 `return await self._请求(方法, 路径, …)`。
- 新分类资源：继承 `核心.资源基座.资源基类`，再在 `资源.客户端.HTTP客户端.__init__` 装配属性。
- 改完 docstring 后运行 `python 文档/tools/API文档生成.py` 同步 API 参考。
- 提交前：`python -m compileall -q kook库` 与真实令牌只读自检。
