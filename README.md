# KOOK Bot SDK

不依赖 `khl` 的 KOOK 机器人通信库：**WebSocket 网关 + REST 接口全覆盖 + 原生 JSON 卡片**，全部使用中文命名与类型注解。

真实环境端到端验证通过（REST 收发消息、WebSocket 网关握手/心跳/启停）。

## 特性

- **三层架构**：`模型`(纯数据) ← `核心`(引擎/网关) ← `资源`(分类 REST)，单向依赖无循环。
- **REST Bot 接口全覆盖**（约 85 个）：消息/私信/会话/用户/服务器/角色/表情/频道/频道角色权限/语音/素材/帖子/模板/邀请/网关。
- **事件网关**：握手、心跳、断线指数退避重连、事件按 sn 去重有序分发。
- **原生卡片**：手写 JSON 卡片 + 链式调用 + 常用卡片模板库。
- **语法糖**：事件回复、命令/关键词路由、等待交互、自动翻页、媒体自动上传直发、ID↔名称缓存解析、权限位枚举、类型化数据对象。

## 安装

需要 Python ≥ 3.10，依赖 `aiohttp`。

```bash
# 从 GitHub 安装
pip install "git+https://github.com/<你的用户名>/kook-bot-sdk.git"
# 或本地安装
pip install -e .
```

## 快速开始

```python
import asyncio
from kook库 import 机器人

机器人实例 = 机器人("你的机器人令牌")

@机器人实例.启动时
async def 启动后(bot):
    print("机器人已上线")
    await bot.发送频道("频道ID", "机器人已上线")

@机器人实例.命令("!ping")
async def 响应ping(事件, 参数):
    await 事件.引用回复("pong! 收到参数: " + 参数)

机器人实例.运行()          # 阻塞运行，Ctrl+C 退出
```

## 常用能力速查

```python
from kook库 import 机器人, 卡片, 创建按钮元素, 构建卡片消息, 状态卡片, 服务器权限

bot = 机器人("令牌")
API = bot.API

# —— 文本 / 卡片消息 ——
await bot.发送频道("频道ID", "你好")                          # 文本自动 KMD
await bot.发送频道("频道ID", 构建卡片消息([卡]))               # 卡片自动序列化

# —— 卡片链式 + 按钮 ——
卡 = (卡片()
      .添加标题模块("标题")
      .添加内容模块("正文")
      .添加分割线模块()
      .添加交互模块([创建按钮元素("确认", "confirm", "return-val")]))
await bot.发送频道("频道ID", 构建卡片消息([卡]))

# —— 预置卡片模板 ——
await bot.发送频道("频道ID", 状态卡片("出错啦", "原因……", "错误"))

# —— 事件处理器里便捷回复 ——
@bot.文本消息
async def 处理(事件):
    if 事件.通道类型 == "GROUP":
        await 事件.回复("回频道")
        await 事件.私信作者("悄悄话")

# —— 交互：命令 / 关键词 / 等待 ——
@bot.命令("!天气")
async def 天气(事件, 城市):
    await 事件.回复(f"{城市}今天晴")

async def 问卷():
    await bot.发送频道("频道ID", "你叫什么名字？")
    回答 = await bot.等待文本(频道ID="频道ID", 超时秒=30)
    await bot.发送频道("频道ID", f"你好，{回答.内容}")

# —— 媒体自动上传直发 ——
await bot.发送媒体("频道ID", "本地/图片.png")          # 自动上传后按图片发送
await bot.发送媒体("频道ID", b"文件字节", "报告.zip")    # bytes 需给文件名

# —— 服务器/频道名解析(ID↔名称缓存) ——
服务器ID = await API.解析服务器ID("我的服务器")
频道ID  = await API.解析频道ID(服务器ID, "闲聊大厅")

# —— 权限位枚举 ——
await API.服务器角色.更新(服务器ID, 角色ID,
                           权限=int(服务器权限.管理消息 | 服务器权限.踢出用户))
```

## 目录结构

```
kook库/
  __init__.py          # 公共入口(重导出)
  模型/                 # 枚举/错误/事件/卡片/卡片模板/类型化对象/常量
  核心/                 # HTTP引擎 / 资源基座(分页助手) / WebSocket 网关
  资源/                 # Bot 聚合客户端 + 机器人主类 + 分类资源
    消息/ 服务器/ 频道/  # 按 KOOK 官方域分组的资源
    用户.py 语音.py 素材.py 帖子.py 模板.py
```

## 接口覆盖清单（Bot）

| 域 | 覆盖 |
|---|---|
| 消息 | 频道消息 11(发送/编辑/删除/回应/置顶/管道)、私信 8、会话 4 |
| 服务器 | guild 6、静音 3、助力历史 1、角色 6、表情 4、邀请 3 |
| 频道 | channel 8、频道角色权限 5、语音 4 + 用户所在语音频道 |
| 其它 | 用户 5、素材上传、帖子 7、模板 4、网关地址 |

## 安全提醒

- 机器人令牌等同密码，**切勿提交到代码仓库**（库已内置 `.gitignore` 忽略 `.env`）。
- 事件处理器之间建议过滤机器人自己的消息，避免机器人互聊触发限流或封禁。
- 管道消息 `/message/send-pipemsg` 使用独立 access_token，与机器人令牌互不相同。
